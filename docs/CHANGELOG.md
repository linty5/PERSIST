# Changelog

## 1.1.0

- Add a PyTorch inference package with one model, automatic download and caching,
  full-frame predictions, Python and batch CLI interfaces, and JSON/CSV exports.
- Keep the original training and evaluation implementation in the
  [research branch](https://github.com/linty5/PERSIST/tree/research).

See the [release notes](RELEASE_NOTES.md) for installation and release contents.

## 1.0.0

- Release the original BMVC 2026 MMAction2 implementation, including training and
  evaluation configurations, three checkpoints and analysis scripts. The
  original assets remain in the fixed
  [v1.0.0 release](https://github.com/linty5/PERSIST/releases/tag/v1.0.0).
